# E-commerce Business Analytics Dashboard

## Project objective
Analyze an e-commerce sales dataset to identify:
- Sales and profit trends
- High-performing categories and products
- Regional performance
- Customer and order patterns
- Discount impact on profitability
- Business opportunities for growth

> **Note:** This repository uses a synthetic/sample dataset created for portfolio practice. It is not Meesho data and is not affiliated with Meesho.

## Tools
- Excel / Power BI
- SQL
- Python (Pandas, Matplotlib)

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Units Sold
- Average Order Value
- Profit Margin

## Suggested Power BI dashboard
### Page 1 — Executive Overview
Cards:
1. Total Sales
2. Total Profit
3. Total Orders
4. Units Sold
5. Profit Margin

Charts:
- Monthly Sales & Profit trend
- Sales by Category
- Sales by Region
- Top 10 Products by Sales

### Page 2 — Customer & Product Insights
- Orders by customer
- Average Order Value by region
- Category vs Profit
- Discount vs Profit
- Top/Bottom products

### Page 3 — Business Recommendations
Summarize:
- Categories driving revenue
- Regions with growth opportunities
- Products with strong profit margins
- High-discount areas where margin is lower

## Example business questions
1. Which categories generate the most sales?
2. Which categories generate the most profit?
3. Which region has the highest order volume?
4. Does a higher discount reduce profit margin?
5. Which products should receive more promotional attention?
6. Which regions need stronger customer acquisition?
